# Citations and grounding

A model asked to cite sources will sometimes cite the wrong one, cite one it never read, or write a sentence with no source at all, and it does so fluently. Grounding is therefore checked by code after generation, not requested in the prompt and trusted. This checker uses facts the program already holds: which sources the tools returned during this answer, and each source's tier from the database. It cannot judge whether a sentence is true; it judges whether each claim points at real evidence the reader can open, and it refuses to let an answer with no evidence pass as an answer. Flags are shown, not hidden, because a visible warning teaches the reader where to double-check.

## What the checker sees

`src/paperwatch/agent/citations.py` holds `check_answer(text, registry)`. The registry is the one Task 14 created for this answer, so the only aliases that can resolve are the ones a tool registered during this conversation. `check_answer` does no I/O, calls no model and reads no database: it is pure text plus that in-memory registry, which makes it cheap to run on every answer and easy to test.

The marker detector is deliberately wider than the canonical `[S1, S2]` form, because a citation the checker cannot recognise is one it cannot flag. It reads any bracket or paren group made only of alias-like tokens, in any case or spacing and with `,`, `;`, `&` or `and` between them: `[s1]`, `(S9)`, `[S 9]`, `[S1; S2]`, `[S1 and S2]`. A recognised group is rewritten to the canonical form, so `[s1]` becomes `[S1]` and the reader sees one spelling. Zero-width characters between `S` and the digits are ignored rather than allowed to hide an alias, and non-ASCII digits are kept, so `[S٣]` is an alias nobody issued instead of an invisible one. Alias groups inside code spans and URLs are content, not citations, and are left alone. A bare `S9` in prose is not a citation, only a bracket or paren group is; that is a known limit of the detector.

The answer is split into sentences on newlines and after `.`, `!` or `?`, including when closing quotes, parens or bold marks follow the stop, and after a marker that is followed by a capital letter (`"... tasks [S1] Most agents..."`). A short list of abbreviations (`etc`, `al`, `e.g`, `i.e`, `vs`, `Fig`, `Dr`) does not end a sentence. Bullets (`-`, `*`, `1.`, `1)`, `•`) are stripped, and a fragment that is only a marker is attached to the sentence before it, because models write both `"...bugs [S1]."` and `"...bugs. [S1]"`.

A sentence is a claim when, with its markers removed, it has at least `CLAIM_MIN_WORDS` (6) words and is not a question. Headings, table rows, code fences, a line ending in a colon and a wholly bold line are layout, not assertions, so they are not claims; a bold line that carries a citation is a real sentence and is judged. A citation is evidence only when it sits in a sentence that passes the claim test: `[S1]` on its own, `See [S1].` or `[S1][S2]` are the model declining to say anything, and the answer becomes the fixed no-support message even though the aliases exist.

## The three flags

- `unknown_source`: a marker names an alias the registry never issued. The alias is masked in the returned text, so it can never reach the reader as a real source: `[S9]` becomes `[?]`, and a mixed marker keeps the invented alias visible in place, `[S1, S9]` becoming `[S1, ?]`. Masking happens before any rendering, so the invented alias is not merely flagged somewhere else.
- `uncited_claim`: a claim sentence with no marker at all. It also fires for a sentence carrying a tier phrase with no citation, whatever its length ("It was accepted at ICLR."), because a reliability claim with nothing behind it is exactly what the reader must not trust. A sentence whose only marker is unknown is reported as `unknown_source` alone, because the model did point at something and the useful repair is "that source does not exist".
- `tier_mislabel`: a sentence whose cited sources are all below `peer_reviewed` while it claims otherwise. The phrases are `peer review` in any hyphenation or spacing (including the non-breaking hyphen), `refereed`, `accepted at/to/for` and `published at/in`. A negation within about three words (`not`, `non`, `yet to be`, `without`, `awaiting`, `un`) makes it an honest label instead, so the "a preprint, not yet peer-reviewed" the prompt asks for is not punished. A sentence may cite several sources and the label holds if any one of them supports it, so `[S1, S2]` with S2 peer-reviewed passes, and a source already cited earlier in the answer still counts, so repeating `[S1]` does not hide a preprint behind its first citation.

Flags name the sentence they came from, with markers and a trailing full stop removed, so the reader can find it in the answer instead of hunting. Identical flags are reported once, and an alias repeated in a tier detail is named once, so a stutter in the model's output does not multiply the warnings. `Flag.detail` clips any alias it echoes, since a model can write one tens of thousands of digits long.

Citations come back in first-seen order and once each, so the source list reads in the order the answer used them. `supported` is true exactly when there is at least one evidence citation and no flag; otherwise the returned text is the fixed `NO_SUPPORT` message rather than the model's uncited prose. The flags are kept with that message for the log, but Tasks 16 and 17 do not show them to the reader: they describe sentences the reader will never see.

## Escaping and links

Everything `check_answer` returns is untrusted in one of two ways, and all of it must be escaped wherever it is rendered into a prompt, an SSE event or a terminal. `CheckedAnswer.text`, `Flag.sentence` and `Flag.detail` are model-authored; `Citation.title` and `Citation.url` are stored third-party data, from a paper or a blog post. Titles and URLs stay raw in `Citation` exactly as `SourceRef` holds them, so the renderer applies one escaping rule.

Links are the renderer's decision and there is no fourth flag kind for them: the answer text is shown as plain text and every link comes from `Citation.url`, so a link the model wrote (`[S1](https://evil.example/x)` or a bare URL in a sentence) never becomes clickable. This is the spec's "every link must match the stored item's URL" enforced by construction, not by parsing the answer.

## Known limits

The checker judges shape, not truth. A sentence under six words is not checked for a citation, so `Reflexion beats GPT-4 by 30.` passes when set on its own; numbers are not checked against the cited source anywhere in M2; and a citation is only a bracket or paren group, so a bare `S9` written in prose is invisible to it. `supported` therefore means "every claim the checker can see points at a source this answer retrieved", not "every statement and number was verified".

## What the tests pin

`tests/unit/test_citations.py` covers distinct citations in first-seen order, a grouped marker, a marker placed after the full stop, markers after bold, quote and paren, a marker that ends a sentence without a stop, an unknown alias flagged and masked with the remaining valid citation kept, the in-place `[S1, ?]`, the wider forms (`(S9)`, `[s9]`, `[S 9]`, `[S1; S2]`, `[S1 and S2]`, zero-width characters) and their canonical rewrite, an uncited claim, a short connective, a heading, a bold heading, a table row, a code fence and a colon lead-in left unflagged, bullets and numbered items read as sentences, abbreviations not ending sentences, a preprint called peer-reviewed flagged while the same sentence citing a peer-reviewed source passes, a repeated citation of a preprint still flagged, the tier synonyms and the three negated honest labels, the six-word boundary, an uncited short tier claim, `[S9]` with a tier phrase reported as unknown only, the flag sentence and detail, deduplicated flags and details, aliases in code and URLs ignored, the clipped echoed alias, flags kept beside the no-support message, and the no-evidence answer for an uncited text, a wholly unknown-cited text, `[S1][S2]` and `See [S1].`. The plan's mutation check accepts every alias the model invents and makes the unknown-alias and no-evidence tests fail, which is what keeps the registry lookup from turning into an honour system.
