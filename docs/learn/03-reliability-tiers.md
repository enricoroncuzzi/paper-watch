# Reliability tiers

Retrieval can only be as trustworthy as what it retrieves. Each stored item carries a reliability tier decided by explicit, testable rules, never by a model's impression: peer-reviewed when a recognised venue accepted it, vetted preprint when there is independent evidence of quality (community upvotes, citations, or authorship by a known lab team), lab blog when it comes from an official engineering feed. Because the tier is data, later stages can filter by it and a post can state "peer-reviewed at ICLR" or "a preprint" truthfully. Evidence arrives late (upvotes over days, citations over weeks, a venue acceptance after months), so the rules are re-applied as it grows, and a tier only ever goes up: an outage or a lagging answer must not demote a paper.
